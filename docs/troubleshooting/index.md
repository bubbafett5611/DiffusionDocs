# Troubleshooting

Troubleshooting pages will focus on visible symptoms, likely causes, and practical fixes.

::: info Start With The Symptom
Good troubleshooting starts with what changed and what failed: model, prompt, seed, resolution, sampler, scheduler, LoRAs, extensions, tool version, and hardware/backend.
:::

## Planned Topics

- distorted hands, faces, or text
- prompt being ignored
- muddy detail or oversharpening
- repeated objects or bad composition
- color and contrast problems
- out-of-memory errors

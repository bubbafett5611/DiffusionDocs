# Guides

Guides are reader-facing pages that help you learn workflows, make practical choices, and build a working mental model of diffusion image generation.

::: tip Start Here
If you are new to diffusion tools, begin with [Getting Started](./getting-started/introduction.md).
:::

## Suggested Path

New readers should start with Getting Started, then move into Workflows and Prompting. LoRA guides make the most sense after you understand models, prompts, and basic generation settings.

If you are already using a tool, jump to the guide that matches your current problem. The guides are designed to link outward to reference pages when a concept needs more depth.

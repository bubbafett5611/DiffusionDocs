## How To Read Tool Pages

Tool pages are not rankings. They are decision aids. A good tool choice depends on hardware, model support, maintenance, privacy needs, workflow complexity, and how much control the reader wants.

When evaluating a tool, check:

- recent maintenance activity
- supported model families
- extension or custom-node ecosystem
- how it stores metadata and workflows
- install/update complexity
- whether it is local, hosted, or both

# Licensing And Sources

Models and adapters can have different licenses, usage restrictions, and source quality.

::: warning Check The Actual License
Do not assume that a model is free for commercial use because it is downloadable. Check the model card, repository, creator notes, and platform terms.
:::

## What To Check

- commercial use
- redistribution
- generated-output terms
- attribution requirements
- restrictions on specific use cases
- whether the model is official, community-trained, merged, or reuploaded

## Source Quality

Prefer sources that provide:

- a model card or project page
- license text or a clear link to it
- base model and training lineage
- intended use and restrictions
- version history or release notes
- hashes or filenames that identify the exact artifact

Reuploads can be convenient, but they may omit context. A model copied between sites can lose license notes, usage restrictions, trigger words, recommended settings, or safety caveats.

## Output Rights Are Not Universal

Some model licenses focus on model weights. Others also discuss outputs, derivatives, redistribution, commercial use, attribution, or prohibited uses. Hosted services may add separate terms for generated content, account plans, training data usage, or API access.

This site cannot determine whether a particular output is safe for a legal or client use. Treat licensing as part of workflow planning, not an afterthought after images are generated.

## Practical Documentation Habit

When using a model for serious work, save:

- model name, version, and source URL
- license name and access date
- checkpoint hash when available
- LoRAs and other adapters used
- hosted service plan or terms page when relevant

::: warning Licenses Can Change Or Be Misread
If the work is commercial, public, regulated, or client-facing, verify the current license and service terms from primary sources. Do not rely on a screenshot, social post, or model filename as proof of permission.
:::
